つかいかた・ルール

あそびかた

  1. 表紙のおばけに、タッチ。おばけの庭に入れます。招待状（日にち・場所・ひとこと）は、表紙の下にあります。
  2. 庭では、左右にスワイプ。パソコンは、ドラッグ・マウスのホイール・左右のボタンでも動けます。
  3. 気になるおばけを、タップ。音と動きのあとに、ハロウィンの豆知識が出ます。「こたえを見る」で、答えと出典がわかります。
  4. おばけは、全部で人。豆知識のおばけ人と、魔女の家の魔女です。会った数は、右上の に出ます。魔女は、ノックして、ダンスのミュージックビデオを見ると仲間入り。全員に会うと、お祝いの画面が出ます。
  5. 庭のまんなかの「魔女の家」をノックすると、魔女のダンスのミュージックビデオ（サビの15秒）が見られます。見ると、魔女に会ったことになります。全編は、その下のボタンから YouTube で見られます。
  6. おばけの友だちが、表紙に集まります。豆知識を1つ見るたびに、表紙のおばけが1人ずつ増えます。9人全員に会う（魔女のダンスも見る）と、表紙が「おばけ大集合」に。友だちにも、見せてあげてね。

右上のボタン

  • スピーカー押すたびに、①ギミック音だけ消える（BGMは鳴ったまま）→ ②ぜんぶ消える → ③もとにもどる
  • ♪BGMをえらびます（ワルツ・マーチ・ゆめ・なし）
  • 見た目なめらか ⇄ ドット絵。いる場所も、見つけた数も、そのままです
  • ?この説明を開きます
  • 全画面アドレスバーなどを消して、画面いっぱいに。もう一度押すと、もどります（できる端末だけに出ます）

招待状のボタン

  • 地図を開く会場の地図が開きます
  • カレンダーに入れるAndroid・パソコンは Googleカレンダー。iPhoneは「iPhoneのカレンダーに入れる」を押して、出てくる「カレンダーに追加」を押します
  • 参加する／欠席するLINEの画面が開きます。返事を送る相手（この招待状をくれたトーク）を選んで、送ってね

出るボタンは、送った人が入れた内容で変わります。

音が出ないとき

  • スマホの「マナーモード（消音）」を、オフにします
  • 音量を上げます。ブラウザの決まりで、音は、最初のタップから鳴りはじめます
  • スピーカーのボタンが「消えた」状態になっていないか、見てみます

つくりかた（1分）

  1. 表紙の下の「招待状をつくる」を押します。もらった招待状では「自分も招待状をつくる」を押すと、もらった内容がコピーされます。もらった招待状は、そのまま残ります。
  2. 日にち・会場・ひとことなどを入れます。空欄の項目は、招待状に出ません。「例を入れる」で、見本が入ります。
  3. 「リンクをつくる」を押します。
  4. 見た目をえらびます。なめらか／ドット絵。受け取った人は、はじめからその見た目で開きます（あとで切りかえもできます）。
  5. 「LINEで送る」を押して、送る相手をえらんで送信。「リンクをコピー」なら、メールやSNSにも貼れます。

お返事をもらう

  • 「参加のお返事を、LINEでもらう」にチェックすると、招待状に「参加する／欠席する」が付きます
  • 返事は、押した人から あなたへの LINE のメッセージで届きます。人数の自動集計は、ありません。届いたメッセージで、数えてね

ルール・注意

  • 入力した内容は、リンクの中に入ります。リンクを知っている人には、全部見えます。住所・電話番号など、見せたくないことは、入れないでね
  • サーバーには、保存されません。リンクが、招待状の本体です。送ったトークを、控えとして残しておくと安心です
  • 書きかえたいときは、新しいリンクをつくって、送りなおします。前のリンクは、前の内容のまま開きます。（つくった直後なら、「この招待状を書きかえる」で直せます）
  • あつめたおばけの記録は、あなたのスマホの中だけに残ります（送った人には届きません）。ブラウザのデータを消すと、はじめからになります
  • 日にちを入れると、「あと◯日」と、カレンダーのボタンが出ます
  • つくった招待状は、そのまま残ります（アドレスの中に入っているため）。新しい招待状をつくり直したいときは、「白紙から、つくる」か、下の「はじめからにする」を使います

リセットすると、次のことが起きます。

  • あつめたおばけと、ミュージックビデオを見た記録を消します（表紙のおばけも、はじめにもどります）
  • 画面の招待状（もらったもの・つくったもの）を外して、見本にもどします。送ったリンクは、そのまま使えます（もらった相手の画面には、何も起きません）
